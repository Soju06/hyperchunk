대역), 시간 하한은 이 VM에서 방법론만 확정하고 절대치는 베어메탈 (P2-6)

## 3. 축 3 — 구조 하한 (critical path / Amdahl) — P2-8 후 재실측

워터폴 3런 (HC_BENCH_TIMELINE, 매 런 PASS): gen 1816.8/1966.8/2063.5.
클린 런 (run2, DAG wall 518.6 — jsonl 중앙값과 일치) 기준:

- **DAG 구조적 CP (워커 무한): 313.7 ms** = 세그먼트 최장 체인 합 287.8
  + prepare 9회 25.9. B-2 442.8 대비 **-29%** — GO-2 가 배리어 성분을
  179 → 25.9 로 붕괴시켰고, s0 체인도 185.8 → 109 (GO-1 의 deco-측 줌
  수혜). l09-간섭 런에선 CP 439/456 — **CP 는 dur-가중이라 이 VM 에선
  [314, 456] 대역** (베어메탈 확정 항목).
- **DAG 는 이제 워커-바운드가 아니라 워크-바운드**: 20T 에서 CPU/20 =
  365 ms > CP 314 ms. wall 518.6 = cpu-busy/20 365.1 + steal-in-span
  42.4 + 유휴 111.2 (스폰 램프 ~50-55 [PT_TLS ~2.5-3 ms/스레드 ×20,
  hc_sched_run 이 매번 신규 스폰] + 세그먼트 드레인/s0 웜업 ~30 +
  배리어 단독 ~25). **분해가 닫힌다** (합 518.7).
- **chain 분해도 닫힌다**: wall 1214.2 = cpu-busy/20 1054.3 + steal
  104.5 + 램프/꼬리 유휴 51.1 + 마진 ~5 (합 1214.9). 가동률 95.8% —
  스케줄 개선 여지 0 (B-2 판정 유지), 남은 것은 스폰 램프 (86 ms skew,
  PT_TLS 함수) 와 VM steal (베어메탈 소멸) 뿐.
- **페이즈 완전 순차** (겹침 0, B-2 그대로): serialize 는 동결 라이트를
  읽으므로 (값-등가 증명 없이는) 겹침 불가. 유일 겹침 후보 chain↔DAG
  융합은 1.065x 로 기각 완료 (B-2 §3-4).
- **합성 워크 플로어 (이 VM, 20T, 현 CPU-sum 고정)**:
  chain 1054.3 + DAG max(365.1, 313.7) + pp 35.7 + lfinal 3.8 + ser
  워커-busy/20 27.1 + sha ~0 = **1486.0 ms**. σ*/Λ* 공간-국소 재설계 +
  융합의 플로어도 (21.09+7.30)/20 + 꼬리 = **1486 ms 로 동일** — DAG 가
  이미 워크-바운드라 융합이 살 수 있는 것은 유휴 겹침뿐이기 때문.
  (B-2 의 1686 ms 는 P2-8 전 CPU-sum 입력 — 본 재계산으로 대체.)
- **갭 계상 (wall)**: 1816.8 − 1486.0 = 330.8 ms = VM steal 146.9
  (chain 104.5 + DAG 42.4; 베어메탈 소멸 항) + 유휴/램프/드레인/배리어
  ~162 (PT_TLS 스폰이 최소 ~110 [chain+DAG+ser 3회 스폰 계단] — TLS
  다이어트 회수 대상) + ser 꼬리 14.1 + 마진 ~8. **미설명 잔여 ≈ 8 ms
  (0.4%)**.
- Amdahl: 순차 잔여 (pp 35.7 + lfinal 3.8 + sha finalize ~0) ≈ 40 ms —
  스레드 무한 상한 = CP-바운드 구간 포함 ≈ chain 워크 여전히 지배.
  20T→∞ 이득은 DAG (365→314) + chain (폭 무제한, 0) ≈ **-51 ms 뿐** —
  스레드 증설은 이 워크로드의 축이 아니다 (B-1 바닐라 2.2x 스케일링
  한계와 대비되는, 우리 쪽의 "이미 다 쓴" 상태).

## 5. 축 4 — ISA 상한 (AVX2 실효율 구조와 AVX-512 근거)

- **FMA 금지는 하한의 일부다** (패리티 불변식, ADR-004 D3/check_no_fma):
  mul·add 가 별도 반올림으로 발행 → FLOP/insn 상한이 FMA 머신의 절반.
  이는 "미설명 갭"이 아니라 **패리티가 사는 비용으로 계상**.
- 동적 벡터 FP (실측 카운트 × 소스 구조): perlin_x4 35.17M 호출 ×
  (46 mul + 29 add + 16 sub) = **vmulpd 1.62G / vaddpd 1.02G / vsubpd
  0.56G** (각 4레인). 여기에 같은 자릿수의 비-FP 가 얹힌다:
  - 셔플/전치: ~56/샘플 ≈ **2.0G** (콘너당 4로드+7셔플 — gradient 전치)
  - **스칼라 해시 체인: 118 movzbl/호출 ≈ 4.15G** (정적 629 insn 중
    118 — perm 테이블 워크는 벡터화 불가 시맨틱)
  - **스필: x4_run 98 스택-mov/호출 × 41.8M ≈ 4.1G** (정적: 52 스토어
    + 46 리로드, frame 0x300; perlin_x4 17+4) — ymm 16개 부족의 실측면
  - 인터프리터 디스패치: 노드 4.3억 × switch
- 즉 **x4 커널의 "FP 아닌 절반"이 정적·동적으로 계량됐다** — ADR-004
  의 AVX-512 인수 분해 (Zen4: 폭 0.50 [더블펌프] × zmm32 3.0 ×
  vpermt2pd 1.35 × mask 1.10 → noise 2.2x, 보수 1.6x; Zen5 8.9x/6.5x;
  파이프라인 전달 **Zen4 +12% / Zen5 +27%**) 중 zmm32 항과 vpermt2pd
  항의 표적이 위 스필 4.1G 과 셔플 2.0G 임을 직접 확인. AVX-512 커널은
  미구현 (P2-6 슬롯) — 배율은 ADR-004 추정치 그대로 인용하고 여기서
  수치를 새로 만들지 않는다.
- 혼합-레인 패리티 비용 (x4 가 스칼라-레이지 위에 얹는 죽은-작업):
  rc/is/blend 혼합 합계 ~0.97M — 노드 4.3억의 **0.2% 미만** (§2). 즉
  AVX2 벡터화의 패리티 세금은 무시 가능 — 남은 것은 구조 (셔플/해시/
  스필) 다.
- 스칼라 폴백 소멸 재확인: x4_scalar_fb = **0** (포화 가드 미발화 —
  P2-4 "도달 불가" 실증), 스칼라 prog 노드 2.56M (x4 의 0.6%).

### 6.2 종결 판정 기준 (제안)

세 축 모두에서 갭이 "계상 목록"에 귀속되면 종결. 실측 근거와 함께:

1. **구조축 — K_struct = 1.10**: 실측 gen wall ≤ 1.10 × [Σ스테이지
   CPU/스레드 + max(CP, CPU/스레드) + Amdahl 꼬리]. 근거: 현재 이
   VM 에서 1816.8/1486.0 = 1.223 인데 그중 steal 147 ms 는 베어메탈
   소멸 항 — 제외 시 1.124. PT_TLS 다이어트 (§7-3) 적중 시 ~1.05 도달
   가능 → 1.10 은 달성-가능하고 느슨하지 않다.
2. **연산축 — 단가-회귀 잔차 ≤ 25%**: 스테이지별 실측 CPU-sum 을
   Σ(카운트_i × c_i) 로 회귀 (c_i = 베어메탈 마이크로벤치 단가). 잔차
   >25% 인 구간만 후보로 남는다. 근거: 카운트는 결정론 (±0.1% 유일
   예외), 단가 오차 + 캐시 상호작용에 25% 마진. **이 축은 베어메탈
   전제** — 이 VM 에선 카운트 고정까지만 완료 (본 노트).
3. **ISA축 — K_fp ≤ 3 (compute-bound 커널 한정)**: x4 커널 실측 사이클
   ≤ 3 × no-FMA FP-포트 하한. 근거: FP 하한 위에 계상된 구조비 (셔플
   2.0G + 해시 4.15G + 스필 4.1G ≈ FP 3.2G 의 3.2배 연산량이지만
   포트가 다름) — AVX-512 (zmm32+vpermt2pd) 적용 후 K_fp≤3 은 도달
   가능 추정. 미달 시 남는 것이 [FMA 금지, 스칼라 해시 시맨틱, 순서
   보존] 뿐이면 그것으로 종결 (패리티가 사는 비용).
4. **판정 무대**: 1·3 은 베어메탈 3런 중앙값, 2 는 단가 마이크로벤치
   동반. l09 는 베어메탈 재실측으로만 판정. 이 VM 에서는 카운트·비중·
   분해-닫힘 (§3) 까지가 확정 범위다.
