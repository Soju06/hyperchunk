# P2-10 — AVX-512 x8 커널 백엔드 + 3-way ISA 등가 게이트 완료 노트 (2026-08-11)

과제 P2-10 (B-3 §7 후보 7, ADR-004 D2 "AVX-512 런타임 디스패치" 슬롯).
**측정 무대 2곳** — 로컬 claw (Zen3 5900X VM, AVX-512 실행 불가: 빌드·
스칼라/AVX2 게이트만) 와 **hc-e6** (OCI, EPYC 9J45 = Zen5 Turin 풀폭
512-bit, 32 vCPU, gcc 13.3 — AVX-512 실행·실측 전부 여기). 모든 수치에
무대를 명기한다. 원격 리포는 검증 무대일 뿐 — 커밋은 전부 로컬 (SoT),
git bundle 로 전송, push 없음.

  검사 (false-PASS 채널 봉쇄). 금지 명령 (vfmadd/vgather/vrcp/vrsqrt/

## 1. 설계 (커밋 e949220 + 08d4f07)

### 1.1 x8 백엔드 (df_simd_avx512.c — df_simd_avx2.c 의 8레인 판)

- **패리티 계약 동일**: 레인 = 독립 평가점, 레인별 연산 시퀀스 스칼라와
  문자 그대로 동일, FMA/rcp/rsqrt 금지, 나눗셈 vdivpd, floor 는
  vrndscalepd(0x09) (전 입력 정확 연산 = libm floor 비트 동일), 포화
  가드 밖 레인 → 전 레인 스칼라 폴백 (x8_scalar_fb **실측 0** — P2-4
  판정 유지).
- **선택 = opmask**: AVX2 의 cmp+blendv 를 `_mm512_cmp_pd_mask` +
  `vblendmpd`/maskz/mask-mul 로 — 비트 선택·+0.0 대입뿐이라 값 무접촉.
  MUL 단락은 maskz_mul (a==±0 레인 = +0.0 대입, 연산 자체 생략 — 스칼라
  분기와 동형), HALF/QUARTER_NEGATIVE 는 mask_mul (양수 레인 src 패스
  스루). jmin/jmax ±0 규칙은 vpmovq2m (DQ) 부호비트 마스크로 AVX2 의
  blendv-부호 트릭과 동형.
- **gradient**: GRAD 16방향을 컴포넌트 SoA (GRADX8/Y8/Z8) zmm 2개×3 에
  상주, vpermt2pd 계열 1회/컴포넌트로 픽 — AVX2 의 코너당 4로드+7셔플
  (P2-4 §4-1 이 지목한 비용) 소멸. 컴파일러는 vpermi2pd 형 (인덱스-
  파괴) 을 선택 — 동일 연산, RA 사정.
- **해시 체인 벡터화 (커밋 08d4f07, B-3 표적 ②)**: perm[256](uint8) 을
  워드로 넓혀 zmm 8개 상주, 256-엔트리 조회 = vpermt2w 4회 + 상위 2비트
  4-way 선택 (vpcmpw/vpblendmw — 전부 BW). 3단 체인을 배치 조회로: L1
  16조회 (A,B) → L2 32조회 (aa/ab/ba/bb) → 코너 2×32조회 → vpmovzxwq 로
  vpermt2pd 인덱스 직결 (스칼라 추출/스택 왕복 소멸). 값-동일 논거:
  전부 정수 (반올림 부재) + 인덱스 산술 두 보수 동치 ((A+iy)&255 ==
  (A+(iy&255))&255, 워드 합 ≤511 오버플로 없음) + vcvtpd2dq 는 정수값
  double 에서 (int) 캐스트 동치 (|좌표|<2^30 가드 위).
- **콜사이트 (noise_chunk.c)**: fill_slice y-8점 (48 = 6×8 + 꼬리 1
  스칼라), select_cell (ix 2 × iz 4) 8점 — density_cell 채움 순서 (iy
  내림, ix, iz) 레인 배열이 보존. vscratch 는 x8 시 [g->n][8] 64B 정렬
  (hc_arena_alloc 은 절대주소 정렬이라 안전). x4/x8 상호 배타.
- **디스패치 (df_isa.c)**: detect 3-레벨 (avx512 f+dq+bw+vl → avx2 →
  scalar, `__builtin_cpu_supports` 가 OS ZMM 상태까지 검사), force 는
  검출 레벨 클램프 (부재 호스트 SIGILL 방지 + 하향 강제 유지 — hc-e6
  에서 --isa avx2 가 x4 경로를 그대로 시험). TU 격리: -mavx512* 는 이
  TU 한정 (P2-4 -mavx2 와 동일 정책).

### 1.2 게이트 (커밋 ce8bf55)

- **df_x8** (ctest #21): test_df_x4 의 AVX-512 판 — scalar/avx512 이중
  실행 9,376 비트 대조, 배터리 동결 동일. AVX-512 부재 호스트 SKIP 77
  (claw 가 이 경우).
- **check_isa_equiv.sh 3-way**: AVX-512 호스트에서 scalar/avx2/avx512
  각각 풀 리전 골든 canonical 판정. 부재 호스트는 avx512 레그만 명시
  SKIP + 2-way 판정 유지 (게이트 약화 없음) — 3-way 실판정은 hc-e6 에서
  이 스크립트 그대로 (본 노트 §3 기록).
- **check_no_fma.sh**: df_simd_avx512(.c).o 멤버 존재 + 명령 비공허 +
  zmm 코드 존재 검사 추가 — avx512 TU 를 판정하지 않는 false-PASS 채널
  봉쇄 (컴파일은 호스트 CPU 무관이라 claw 에서도 유효). FMA 정규식은
  zmm 형도 동일 mnemonic — 기존 패턴이 커버.
- bench `--isa avx512` (+ 리포트 3-way 라벨), X8 카운터 8종 (B-3 규율 —
  x8_node 만 HC_CTR_HOT).

## 4. ADR-004 인수 대비 실제

| ADR-004 추정 (Zen5) | 실측 (hc-e6 Zen5) | 판정 |
|---|---|---|
| noise 커널 8.9x / 보수 6.5x | **커널 유도 1.55x** (noise 스테이지 1.176x) | **대폭 미달** |
| 파이프라인 전달 +27% | FREE gen wall **+6.7%** | 미달 — 2요인 복합 |
| Zen4 전달 +12% (과제 지문 인용치) | (Zen4 무대 없음 — 미실측) | Zen5 실측이 +6.7% 이므로 Zen4 는 그 이하로 추정 |

미달 원인 분해:

1. **zmm32 3.0x 인수 과대**: ADR-004 는 ymm16 포트가동률 33% (스필
   지배) 가정 — 실제로는 OoO 윈도우가 x4 스필의 상당분을 이미 숨기고
   있었다. 정적으로 스필 점당 -54~87%·해시 소멸·셔플 -58% 인데 커널
   1.55x — 남은 결박은 FP-포트/의존-체인 (FMA 금지 하의 mul→add 지연
   체인). B-3 §6.2 K_fp≤3 판정의 사전 신호 — 확정은 베어메탈 (P2-6).
2. **전달 비중 축소**: ADR-004 산정 시점 대비 P2-8/9 가 noise 외 축을
   이미 깎아 커널이 전체 gen CPU 의 ~18% (noise 8.67 CPU-s 중 42% ≈
   3.6 / 전체 ~20 CPU-s). 1.55x 커널 → wall +6~7% 는 Amdahl 정합 —
   측정 불일치가 아니라 인수 시점 차이.
3. 신규 실측 항: **8폭 죽은-레인 세금 +3.8%** (x4 는 +0.2%) — 폭
   확대의 패리티 비용. 무시 가능 수준이나 16폭 환상은 여기서 꺾인다.

**그래도 GO 가치는 성립**: noise CPU -14.9% 는 실측 최대 잔여 스테이지
의 실질 인하이고, "AVX2/AVX-512 두 백엔드 출력 해시 동일" flex (ADR-004
Why) 가 3-way 게이트로 실증됐다.

## 5. B-3 갭 테이블 갱신 (§6.1 대비 변동 행만 — 무대: hc-e6)

| 구간 | B-3 (claw, avx2) | P2-10 후 (hc-e6, avx512) | 갱신 |
|---|---|---|---|
| 04 x4/x8 커널 | ~5.7 CPU-s; 셔플 2.0G + 해시 4.15G + 스필 4.1G 계량 | 커널 cycles 10.9% (17.0%→); **해시 항 소멸, 셔플 점당 -58%, 스필 점당 -54~87%** | ISA 축 표적 3건 회수 완료 — 잔여는 FP-포트/의존-체인 + 죽은-레인 3.8% (패리티 비용 계상) |
| ISA 축 (§5) | AVX-512 미구현 — ADR 추정치 인용 | **실측 대체**: 커널 1.55x, noise 1.176x, wall 1.067x (Zen5) | §7 후보 7 **완료**; K_fp 판정 입력 확보 (확정은 베어메탈) |
| 스칼라 노이즈 잔여 | perlin 스칼라 5.61% (B-3 표) | sample_scaled 7.47% + octaves 3.40% — **벡터 커널 추월** | 차기 ISA-축 후보는 커널이 아니라 스칼라 잔여 (단, 배치 축 부재 — P2-4 §4-2 기각 논거 그대로) |

K_struct/CP/워크플로어 행은 무변동 (이 GO 는 연산축 전용 — DAG/스케줄
무접촉, surface/carvers/deco CPU 동등 실측).

## 6. 함정 기록 (다음 태스크용)

- **GCC ASan fake-stack(UAR) 는 32B 정렬만 보장** — zmm 64B 스택 슬롯과
  충돌: 컴파일러가 _mm512_loadu 를 vmovapd 로 접은 지점에서 미정렬
  #GP(SIGSEGV) (hc-e6 free_region ASan 실발화, 폴트 주소 32B-정렬
  실측). 회피 = 해당 TU 만 `--param=asan-use-after-return=0` (GCC 판
  스위치; clang 의 -fsanitize-address-use-after-return=never 는 GCC 에
  없다). **로컬(비-AVX512 호스트)에선 원리적으로 재현 불가 — AVX-512
  코드의 sanitizer 게이트는 원격 실행이 유일한 커버다.**
- objdump 아카이브 멤버명은 `df_simd_avx512.c.o` (.c 포함) — 멤버 추출
  awk/grep 패턴에 `(\.c)?\.o` 필요 (check_no_fma 에서 실제로 밟음).
- 카운터 덤프는 `phase name value` 형식 — `^x8_` 앵커 grep 은 공백
  (set -e 아래 스크립트 사망). B-3 노트의 원형 확인 후 파싱할 것.
- hc-e6 perf 는 paranoid=4 기본 — sudo sysctl 1 → 측정 → 4 원복+검증
  (P2-5/B-3 규율 그대로).
- **8폭 죽은-레인 세금은 실재 (+3.8% 레인-샘플)** — 혼합-레인 세그먼트
  실행 확률이 폭에 단조 증가. 더 넓은 배치 (미래 ISA) 견적 시 이 항을
  0 으로 두지 말 것.
- 컴파일러는 vpermt2pd 대신 vpermi2pd 형을 낼 수 있다 (동일 연산,
  인덱스-파괴 RA 선택) — "vpermt2* 존재" 를 정규식으로 검사한다면
  `vperm[ti]2` 로.

## 7. 기각/안-함 판정

1. **vpgatherdd 해시** — 설계 기각. ADR-004 의 Zen 게더 마이크로코드
   근거 유지 + vpermt2w 상주 테이블이 이미 스칼라 대비 압승 (movzbl
   224→0, perlin insn 점당 3.1x) — 게더 실험의 기대 이득 없음.
2. **VBMI vpermb (바이트 테이블 4 zmm)** — 가드레일 기각: Zen4 기준선
   (F+DQ+BW+VL) 위반. hc-e6(Zen5) 에는 있으나 이식성 계약이 우선.
3. **스칼라 해시 유지 (s1 형상)** — s2 실측으로 대체: noise CPU 추가
   -5.5% (7803.6 → 7373.3), perlin_x8 정적 939 → 428 insn. s1 은 커밋
   이력에 남아 재현 가능.
4. **SP/BLOCK 콘 x8 화 / 옥타브-수직 SIMD / mixed-lane 세분화** — P2-4
   §4 기각 판정 그대로 (배치 축 부재 / 수평 리덕션 금지 / 26.2 지형
   무이득). 스칼라 잔여가 커널을 추월한 지금도 (§2.3) 축 부재 논거는
   변하지 않는다.
5. **-mprefer-vector-width=512 등 튜닝 플래그** — 안 함. 인트린식이
   명시적이라 불필요, 자동 벡터화 개입 최소화.
