## 2. 조항 1 — K_struct (hc-e6 20T 재확인; P2-9 값 인용)

## 3. 조항 2 — 단가-회귀 잔차 (≤25%)

### 3.1 방법 (엄밀성 라벨 — 보수적 해석 기록)

c_i 를 세 방법으로 확보하고 라벨을 명기한다. B-3 §8-3 의 마이크로벤치
목록 중 고립-가능 프리미티브 (커널/줌/sha) 는 **독립 마이크로벤치**
(순환성 0), 고립-불가 항목 (aquifer/룰트리/카버/피처) 은 **1T 전용런
perf 귀속** 또는 **스테이지-스코프 단가** — 이 항들의 잔차는 "1T 단가
× 결정론 카운트가 16T 병렬 실측을 설명하는가" 라는 전이 검정이다
(순환성 부분 잔존 — §7 캐벳 1). 카운트는 전부 결정론 + claw 와 비트
동일 재확인.

  정적 가중 보정 시 add-측 플로어 +4.8%, K_fp ~9.8 로 **유리 방향 2차항**.
  경계: 1T 프로세스-전체 vector add+sub 2.822G 를 전량 커널 귀속해도
  플로어 ≤1.411G → **K_fp ≥ 6.3** (지형-믹스로 3 미만 불가)
- 프로덕션 (215.4M 노드): **mul 1.601G, add 1.245G, sub 0.484G, div 74.1M**
- 포트 하한 (2 mul + 2 add 포트, ADR-004 모델 = Zen5 실물과 일치 [FMUL
  2파이프 + FADD 2파이프, FADD 는 FMA 파이프에서 실행 불가 — 분모를
  올릴 여지 없음]): max(1.601/2, 1.729/2) = **0.8645G cyc** (add-측
  결박; div 미포함 — 보수 방향)

### 4.2 분자 — 커널 실측 사이클

- 1T in-situ 커널-TU (x8_run 8.04% + perlin_x8 3.84% + octaves_x8 1.00%
  + stream 2.87% = 15.75% × 56.54G) = **8.905G cyc** = 41.3 cyc/노드-exec
- micro 독립 (커널-루프 = select/라우팅 포함 분자 — 더 큼): wall 중앙값
  1161.3ms × 4.058GHz = 4.713G / 106.03M 노드 = 44.45 cyc/노드 →
  K_fp(micro) 11.07 — in-situ 판정치보다 높음, FAIL 재확인

### 4.3 판정

**K_fp = 10.30** (주판정). 정의 민감도: div 5cyc 가산 분모 → 7.61,
B-3 스케치의 perlin-only 분모 → 19.9, stream 제외 분자 → 8.42.
강건성: 최대-관대 계상 (셔플/cvt 전 유형 플로어 포함 + 4파이프 유연
가정 + 프로세스-전체 카운트 상한 귀속) 으로도 **K_fp ≥ ~4.5** — 3 미만은
어떤 방어-가능 분모로도 불가. **조항 3 FAIL.**

### 4.4 결박 판별 + 폴백 조항 검토

- **포트 압력 아님**: mul-포트 가동률 9.0%, add-포트 9.7%.
- **의존-체인 결박**: SMT 동일코어 co-run (고정 워크, cpu4+5) 합산
  **1.52x** (포트-결박이면 ~1.0x; 크로스-코어 대조군 +0.7%/+4.6%,
  평균 +2.6% — 사이클 밴드 대역 내) — 이슈 슬롯의 절반가량이 체인
  (연산+로드) 지연으로 유휴. 1.52 는 1차 프록시다: SMT 의 프론트엔드/
  리타이어 분할·L1 공유는 과소 방향, 단일-스레드 인터리브의 레지스터
  압력 부재는 과대 방향; co-run 의 ~28% 는 상대 인스턴스의 비계측
  nc_init 창과 중첩 (소폭 바이어스).
- 체인의 산술 정합: 노드당 FP 15.8 op, 지연 2-3cyc (Zen5 FADD 2cyc
  포워딩/3cyc, FMUL 3cyc) — 임계 체인 ~8-10 op 가정 시 20-30cyc +
  퍼뮤트/로드 지연 ≈ 실측 41.3 과 정합. 체인을 늘린 것은 패리티다
  (FMA 금지 = mul→add 융합 불가, 순서 보존 = 재결합 금지) — 여기까지는
  폴백 서사와 일치.
- **그러나 폴백은 닫히지 않는다**: 같은 SMT 실험이 회수 수단을 특정한다
  — 두 하드웨어 스레드가 회수한 슬랙은 **단일 스레드가 독립 콘-스트림
  2개를 인터리브해도 회수 가능** (셀들은 상호 독립, zmm32 에 레지스터
  여유, 값-보존 — 레인별 연산 시퀀스 불변). 이는 [FMA 금지/해시/순서
  보존] 어느 것에도 속하지 않는 구현 축이다. 스칼라 해시 항은 이미
  소멸 (P2-10) 이므로 폴백 목록 자체도 현행화가 필요하다.
- **신규 GO 후보 — x8 커널 2-웨이 스트림 인터리브**: 기대 커널 배율
  1.3~1.5x (SMT 1.52x 가 상한 근사; 동일-스레드는 L1 비공유 이득,
  레지스터 압력 증가는 감점), noise CPU −8~12%, gen wall −3~5% (16T
  환산). 리스크: x8_run 인터프리터 이중화 복잡도, 스필 재유입.

**조항 3 판정: FAIL — ISA/커널 축은 하한 미도달이며, 잔여가 패리티
비용만이 아님을 실측이 증명. 종결 선언 불가.**

## 7. 정직 캐벳 (이 증명의 엄밀성 수준)

1. **공학적 하한이다** — 수학 증명이 아니다 (B-3 엄밀성 선언 승계).
   조항 2 의 in-situ c_i 는 같은 코드의 1T 실측에서 왔으므로 해당 항의
   잔차는 "1T→16T 전이 검정"이지 완전 독립 예측이 아니다. 완전 독립
   예측은 커널 (noise 의 36%, 전체 chain CPU 의 22%) · 줌 · sha 에서
   성립하고 셋 다 닫혔다.
2. **무대**: hypervisor 하 VM. 적격성은 in-core 축에서 실측 증명 (§1),
   사이클 밴드 ±3.5% — K_struct 1.085 vs 1.10 은 밴드 내 여유가 얇다
   (자기-일관 하한 1.083 / 밴드 반영 상한 ~1.12 — 상한이 기준을 넘으므로
   TL;DR 의 PASS 에도 이 캐벳을 병기했다). BM 재실측 시 K_struct 재확인
   권고. 캐시 크기 오보고는 사이클 판정 무관하나 캐시-용량 추론에는 부적.
3. **메모리-대역 항목 (deco/l09)**: 자기-경합 +22~23% 실측은 이웃-공유
   DRAM 환경값 — BM 대역폭 모델 (STREAM + 레이턴시 체인) 없이는 확정
   불가. in-core 판정에서 제외했다.
4. 조항 3 의 분모는 포트-모델 (ADR-004) 기준 — 체인-지연 하한 모델로는
   K 가 1 대에 근접할 수 있으나 (§4.4 산술), 그 모델의 도출 (그래프
   임계-경로 산출) 은 미완 (#2). **기준 완화 없이 FAIL 로 기록한다.**
5. 20T 프로토콜 수치는 SMT 인플레이션 (+11~22%) 을 포함 — 단가-회귀의
   판정 무대는 16T 코어-핀이며 이는 본 노트가 도입한 해석이다 (조항
   원문은 스레드 수 미지정; 물리 단가와 카운트의 대응이 성립하는
   구성을 택했다).
6. 조항 3 원문의 판정 대상은 "x4 커널"이다 — 본 노트는 현행 출하 커널
   x8 (P2-10 이후 디스패치 기본) 로 판정했다 (해석 기록; 조항 의도는
   "compute-bound 커널 한정"이고 x4 로 판정해도 FAIL 방향 동일).

## 8. 판정 선언

**OPEN.** 조항 1 (구조)·2 (연산) 는 이 무대에서 충족 — wall 스케줄링과
연산량 모델은 닫혔다. 조항 3 (ISA/커널) 은 K_fp 10.3 으로 미충족이며,
폴백 (패리티-비용 종결) 은 SMT 실험이 반증했다: **의존-체인 슬랙이라는
실측-근거 회수 축 (2-웨이 인터리브) 이 남아 있는 한 "이론적으로 최적화
불가능" 선언은 성립하지 않는다.** 종결에 필요한 것: ① 커널 인터리브
GO 실행 (기대 wall −3~5%), ② 그 후 K_fp 재판정 + 미달 시 체인 하한
(임계-경로) 산출로 폴백 확정, ③ (형식 요건) BM 무대에서 K_struct/K_fp
절대값 재확인. ①② 는 hc-e6 로 충분하다 (§1).

## 9. 함정 기록 (다음 태스크용)

- **fp_ops_retired_by_type 은 op 단위** (512-bit 명령 = 1) — FLOP 로

  도구에 추가했다 (f4d32a9 후속 커밋). 프로덕션 미스율 5.43% ≈ micro
  정상상태 5.55% 라 혼합 단가 직접 적용이 성립한 것은 우연이 아니라

  스테이지 귀속에 넣으면 오염. 프로파일-스테이지 대응 전에 setup_end
